## Summary
Phase 1 wired up the existing skeleton: the critical context mounting gap was fixed, the admin panel became accessible, module toggles now have real effect on the UI, and the announcements system gained a full admin compose/manage interface.

---

## Changes

### `src/App.jsx`
- **Mounted `SiteConfigProvider`** wrapping the entire app tree — fixes the crash in `AdminPanel` and enables config-aware rendering everywhere.
- **Added `/admin` route** pointing to `AdminPanel` (was missing entirely).
- **Added `/coming-soon` route** pointing to `ComingSoon`.
- **Added `ModuleRoute` guard component** — wraps `/tasks` and `/merchandise` routes. If the corresponding `site_config` key is `false`, the user is redirected to `/coming-soon` instead of the page loading. Replaces dead toggle switches with functional gating.

### `src/components/Navigation.jsx`
- **Imported `useSiteConfig`** — nav now reads `is_taskboard_enabled` and `is_store_enabled` from site config.
- **Filtered nav links** — Task Board and Merchandise links are hidden when their respective modules are disabled by an admin.
- **Added Admin Panel nav link** — visible only to users where `isAdmin === true`. Appears in both the desktop user dropdown menu and the mobile drawer, separated by a divider from the user-facing links.
- Minor cleanup: consolidated `handleCloseUserMenu` calls.

### `src/pages/AdminPanel.jsx`
- **Added full Announcements management section** below the existing module toggles card:
  - "New Announcement" button opens an inline compose form.
  - Form fields: **Title** (required), **Body** (required, multiline), **Date** (required, defaults to today).
  - On publish: inserts into Supabase `announcements` table with `title`, `description`, `date` columns.
  - Success/error feedback inline.
  - **Published announcements list** — fetches all existing announcements on load, shows title, date chip, body preview, and a delete (trash) button per row.
  - Delete confirmation is handled via loading spinner on the button; the row is removed from local state immediately on success.

### `src/pages/Announcements.jsx`
- **Removed non-functional "Read More" button** — the full `description` text was already displayed; the button navigated nowhere and caused confusion.

### `src/components/HomeAnnouncements.jsx`
- **Made announcement items clickable** — each item now navigates to `/announcements` on click, with `cursor: pointer` styling. Gives landing page visitors a clear path to the full notice board.

### `src/components/StorePreview.jsx`
- **Fixed broken "Go to Store" link** — was navigating to `/store` (404). Corrected to `/merchandise`.
